# Brawl Arena

Прототип top-down arena game на Three.js + TypeScript + Vite + Socket.IO.  
Без React, Redux и сложной архитектуры. UI сделан обычным HTML/CSS поверх canvas.

Важно: проект не использует оригинальные ассеты Brawl Stars. Карта сделана как оригинальная стилизация под мультяшную арену, чтобы не копировать чужие текстуры один в один.

## Запуск

```bash
npm install
```

Терминал 1:

```bash
npm run dev:server
```

Терминал 2:

```bash
npm run dev:client
```

Открой в браузере:

```text
http://localhost:5173
```

Для телефона в одной Wi-Fi сети открой:

```text
http://IP_ТВОЕГО_ПК:5173
```

Socket.IO сервер работает на порту `3001`.

## Управление

Desktop:
- WASD / стрелки — движение
- мышь — прицел
- клик / Space — выстрел

Mobile:
- левый джойстик — движение
- правая кнопка — выстрел
- в портретной ориентации показывается плашка «переверните телефон»

## Структура

- `src/game/World.ts` — карта, препятствия, декор и коллизии
- `src/game/Game.ts` — игровой цикл, камера, выстрелы, раунд
- `src/game/Player.ts` — персонаж и HP-bar
- `src/game/Input.ts` — клавиатура, мышь, мобильный джойстик
- `src/net/NetClient.ts` — Socket.IO клиент
- `server/index.ts` — Socket.IO сервер
- `src/style.css` — HTML/CSS интерфейс
